# Security policy

## Reporting a vulnerability

Please use the repository's GitHub **Security** tab and select **Report a
vulnerability** to send a private report. Do not put exploit details or
unfixed vulnerabilities in a public issue.

Include a concise description, affected version or commit if known, impact,
and a reproduction using synthetic inputs. Before sharing logs or configuration,
remove raw private prompts and transcripts, credentials, account details, and
private machine or account paths. There is no response-time guarantee.

## Scope and trust boundary

Demon Mode is a local advisory resource policy. It relies on the local
operator's inputs and does not replace operating-system, application, or
provider controls. Advisory hooks do not authorize work and cannot grant,
change, or bypass permissions.

This repository notice is not a security audit, certification, or proof of
native enforcement.
